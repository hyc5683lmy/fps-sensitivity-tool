# FPS 灵敏度调优器

一个帮助 FPS 玩家找到个人最佳灵敏度设置的纯前端工具。

## 功能

- **流派分析**：输入 DPI 和游戏内灵敏度，计算 cm/360°，判断你是低敏（大臂流）还是高敏（手腕流）
- **实测验证**：甩枪点靶测试 + 跟枪追踪测试，根据实际操作表现给出调整建议
- **参考灵敏度生成**：基于测试结果给出具体的灵敏度建议值，一键应用
- **测试历史对比**：保存测试记录，对比调整前后的表现变化
- **跨游戏转换**：三角洲行动 ↔ Valorant 灵敏度等效换算

## 支持游戏

- 三角洲行动（默认，支持水平/垂直分轴灵敏度）
- Valorant

## 使用方法

直接在浏览器中打开 `index.html` 即可使用，无需安装任何东西。

## 技术特点

- 纯前端：HTML + CSS + JavaScript，无后端依赖
- 无数据收集：所有计算在浏览器本地完成
- 无外部库依赖：单文件即可运行
- 免责声明：所有结果仅供参考，非官方标准
